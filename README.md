# TechSphire website

A fast, responsive, multi-page website for TechSphire, an IT services and IT consulting company, built with plain HTML, CSS and JavaScript — no build step or dependencies.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Home — hero with animated globe, practice areas, platforms, industries, assessment, engagement process, FAQ |
| `services.html` | Full service catalog: 10 practice areas, 47 services (each linkable, e.g. `services.html#generative-ai`) |
| `industries.html` | Industries served, with focus areas for each |
| `about.html` | Story, mission, values and leadership team |
| `careers.html` | Benefits and open roles |
| `contact.html` | Contact form and company details |
| `privacy.html` | Starter privacy policy |
| `404.html` | Not-found page |

Shared assets live in `assets/` (`css/styles.css`, `js/main.js`, `img/logo.svg`).

## Preview locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Customise before going live

Search and replace these placeholders across all `.html` files:

- `hello@techsphire.com`, `support@techsphire.com`, `careers@techsphire.com` — your real email addresses
- `+1 (000) 000-0000` / `tel:+10000000000` — your phone number
- `123 Business Street…` in `contact.html` — your office address
- Social icons in the footer (`href="#"`) — links to your LinkedIn, X and Facebook pages
- Leadership names and roles in `about.html`
- Open roles in `careers.html`
- Privacy policy text in `privacy.html` (have it reviewed for your jurisdiction)

**Branding:** colours are defined as CSS variables at the top of `assets/css/styles.css` — change `--brand`, `--brand-hover` and `--brand-tint` to recolour every button, link and accent. 
**Logo files** (in `assets/img/`):

| File | Use |
| --- | --- |
| `logo.svg` | Icon only, detailed — large uses (presentations, signage, social avatars) |
| `logo-small.svg` | Icon only, bolder dots — small sizes (website header, browser tab icon) |
| `logo-full.svg` | Icon + name, for light backgrounds (documents, email signatures) |
| `logo-full-white.svg` | Icon + name, for dark backgrounds |
| `logo-512.png` | High-resolution icon (transparent) for profiles and apps |
| `apple-touch-icon.png` | Home-screen icon on phones |

The full logos use the Inter font; for print, open them in a design tool and convert the text to outlines.

**Editing content:** every page is generated by `tools/build_site.py`, which holds the navigation, mega menu, footer, the service catalog, industries and all page text. Edit that file, then run:

```bash
python3 tools/build_site.py
```

Don't edit the `.html` files directly — the next build overwrites them. Styles live in `assets/css/styles.css` and behaviour (slider, menus, globe, tabs) in `assets/js/main.js`.

**Photos:** stock photos in `assets/img/photos/` come from [Unsplash](https://unsplash.com/license) (free for commercial use, no attribution required). Replace them with your own office and team photos where you can — keep the same file names, or update the names in `tools/build_site.py`.

## Contact form

By default, submitting the form opens the visitor's email app with the message pre-filled, addressed to the `data-email` value on the form.

To receive submissions directly instead, create a free form endpoint (e.g. [Formspree](https://formspree.io)) and add it to the form in `contact.html`:

```html
<form ... id="contact-form" data-endpoint="https://formspree.io/f/your-id">
```

## Deploy

This is a static site and can be hosted anywhere:

- **GitHub Pages:** repository *Settings → Pages → Deploy from a branch*, choose the branch and `/ (root)`.
- **Netlify / Vercel / Cloudflare Pages:** import the repository; no build command, publish directory is the root.
